## Задание 3.1. Классы эквивалентности и граничные значения

---

### Поле «Номер телефона»

**Требование:** только российский мобильный номер в формате +7 (XXX) XXX-XX-XX, 11 цифр, начинается с +7.

#### Классы эквивалентности

| № | Класс | Тип | Пример значения |
|---|-------|-----|-----------------|
| К1 | Корректный российский мобильный номер в формате +7 (XXX) XXX-XX-XX | ✅ Валидный | `+7 (900) 123-45-67` |
| К2 | Поле пустое (ничего не введено) | ❌ Невалидный | `` (пустая строка) |
| К3 | Номер содержит буквы или спецсимволы вместо цифр | ❌ Невалидный | `+7 (abc) xyz-de-fg` |
| К4 | Номер начинается не с +7 (другой префикс или без префикса) | ❌ Невалидный | `+375 (29) 123-45-67` или `89001234567` |
| К5 | Количество цифр меньше 11 (короткий номер) | ❌ Невалидный | `+7 (900) 123-45` |
| К6 | Количество цифр больше 11 (слишком длинный номер) | ❌ Невалидный | `+7 (900) 123-45-678` |

---

#### Граничные значения для поля «Номер телефона»

Граница задаётся длиной ввода. Корректный номер содержит ровно 11 цифр.

| № | Граничное значение | Тест | Вводимое значение | Ожидаемый результат |
|---|--------------------|------|-------------------|---------------------|
| Г1 | 10 цифр (одна меньше минимума) | Негативный | `+7 (900) 123-45-6` | Ошибка валидации: «Введите корректный номер телефона» |
| Г2 | 11 цифр (точно по требованию) | Позитивный | `+7 (900) 123-45-67` | Поле валидно, форма разрешает отправку |
| Г3 | 12 цифр (одна больше максимума) | Негативный | `+7 (900) 123-45-678` | Ошибка валидации: «Введите корректный номер телефона» |
| Г4 | Пустое поле (0 символов — крайний минимум) | Негативный | `` | Ошибка: «Поле обязательно для заполнения» |

### Поле «Ваше имя»

**Требование:** только буквы кириллицы, от 2 до 40 символов.

#### Классы эквивалентности

| № | Класс | Тип | Пример значения |
|---|-------|-----|-----------------|
| К1 | Строка из кириллических букв длиной от 2 до 40 символов | ✅ Валидный | `Анна` / `Александра` |
| К2 | Поле пустое (ничего не введено) | ❌ Невалидный | `` (пустая строка) |
| К3 | Строка содержит латинские буквы | ❌ Невалидный | `Anna` / `Ivan Petrov` |
| К4 | Строка содержит цифры | ❌ Невалидный | `Анна1` / `123` |
| К5 | Строка содержит спецсимволы или пробелы | ❌ Невалидный | `Анна-Мария` / `Анна!` |
| К6 | Строка из кириллических букв длиной 1 символ (меньше минимума) | ❌ Невалидный | `А` |
| К7 | Строка из кириллических букв длиной более 40 символов (больше максимума) | ❌ Невалидный | `АбвгдеёжзийклмнопрстуфхцчшщъыьэюяАбвгд` (41 символ) |

---

#### Граничные значения для поля «Ваше имя»

| № | Граничное значение | Тест | Вводимое значение | Ожидаемый результат |
|---|--------------------|------|-------------------|---------------------|
| Г1 | 1 символ (одна меньше минимума) | Негативный | `А` | Ошибка валидации: «Имя должно содержать не менее 2 символов» |
| Г2 | 2 символа (точно минимум) | Позитивный | `Ян` | Поле валидно, форма разрешает отправку |
| Г3 | 40 символов (точно максимум) | Позитивный | `Абвгдеёжзийклмнопрстуфхцчшщъыьэюяабвг` | Поле валидно, форма разрешает отправку |
| Г4 | 41 символ (одна больше максимума) | Негативный | `Абвгдеёжзийклмнопрстуфхцчшщъыьэюяабвгд` | Ошибка валидации: «Имя не должно превышать 40 символов» |
| Г5 | Пустое поле (0 символов — крайний минимум) | Негативный | `` | Ошибка: «Поле обязательно для заполнения» |

- Поле «Ваше имя» заполнено
- Поле «Номер телефона» заполнено
- Номер телефона валиден (формат +7 (XXX) XXX-XX-XX, 11 цифр)

### Расшифровка правил

| Правило | Условия | Ожидаемый результат системы |
|---------|---------|----------------------------|
| **П1** | Имя — пусто; Телефон — пусто | Оба поля выделены как обязательные. Кнопка «Подтвердить запись» заблокирована (или показывается ошибка при клике). POST-запрос не отправляется. |
| **П2** | Имя — заполнено; Телефон — пусто | Поле «Номер телефона» выделено как обязательное. Отправка заблокирована. |
| **П3** | Имя — пусто; Телефон — заполнен, но невалиден | Поле «Ваше имя» выделено как обязательное; «Номер телефона» — с ошибкой формата. Отправка заблокирована. |
| **П4** | Имя — заполнено; Телефон — заполнен, но невалиден | Поле «Номер телефона» показывает ошибку валидации (некорректный формат). Отправка заблокирована. |

---

> **Вывод:** Запись подтверждается (POST-запрос отправляется) только при выполнении всех трёх условий одновременно. При невыполнении хотя бы одного — система блокирует отправку и показывает соответствующее сообщение об ошибке.
